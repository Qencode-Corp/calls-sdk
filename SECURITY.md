# Security

Report vulnerabilities in these SDKs or in the Qencode Calls service to security@qencode.com.
Do not open a public issue for security problems. We acknowledge reports within two business
days and coordinate a fix and disclosure date with you.

Scope: the packages in this repository, the credential flow they implement, and the sample
backends. Findings about the Qencode API itself are welcome through the same address.
